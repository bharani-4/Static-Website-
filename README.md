# Static-Website-Using HTML and CSS 
Course Website (Static Web Project)

This project is a static educational website built using HTML, CSS, JavaScript, and XML as part of an academic assignment. It demonstrates structured web design, styling, form validation, and data representation using XML.

🚀 Features
🏠 Home Page
Website introduction
Navigation menu
Banner / images for visual appeal
📖 Courses Page
Display of all available courses using course cards
Each course includes:
Course Title
Instructor Name
Price
Ratings
📘 Course Details Page
Detailed course description
Instructor information
Course curriculum
Duration of the course
Enroll button
🔐 Register / Login Page
User registration form:
Name
Email
Password
Confirm Password
Login form
JavaScript validation for:
Required fields
Email format
Password matching
📞 Contact Page
Contact information:
Address
Email
Phone number
Inquiry form for users
🎨 Styling (CSS)
External stylesheet: styles.css
Features:
Custom fonts and colors
Responsive layout using CSS Grid
Proper spacing and alignment
Hover effects on buttons and links
📂 XML & XSD Implementation
XML File
Stores structured data such as course details
XSD File
Validates the XML structure
Ensures proper formatting and data types
🛠️ Technologies Used
HTML5
CSS3
JavaScript
XML & XSD
